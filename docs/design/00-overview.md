# StreamGrab - 项目概述

## 项目名称

**StreamGrab** - 现代化的流媒体下载工具

## 项目定位

将 N_m3u8DL-RE 与 FFmpeg 双引擎封装为一个功能完善、界面优美、易于使用的跨平台桌面应用程序。N_m3u8DL-RE 引擎处理 HLS/DASH/MSS 流媒体，FFmpeg 引擎处理 HTTP 直链视频——按 URL 类型自动分派，用户无需选择工具（策略模式，详见 `07-tool-config-architecture.md`）。

## 核心目标

### 1. 用户体验

- 零学习成本，开箱即用
- 直观的视觉反馈，实时进度展示
- 一键下载，智能默认配置
- 双引擎自动分派，无需关心底层工具

### 2. 功能完整

- N_m3u8DL-RE 处理流媒体（HLS/DASH/MSS），FFmpeg 处理 HTTP 直链
- 支持点播和直播两种模式
- 支持批量下载和任务队列管理
- 支持流选择、解密、代理等高级功能
- 任务级覆盖（TaskOverrides）+ 全局默认三层配置
- 历史记录真实持久化（任务终态自动快照）
- 定时开始（datetime-local + 调度器）

### 3. 界面美观

- 现代化设计语言
- 深色/浅色主题支持
- 流畅的动画过渡
- 响应式布局

### 4. 可扩展性

- 引擎策略架构（DownloadEngine trait），新增下载工具五步扩展
- 三层配置模型 + tool_settings 通用表，新增工具零 DDL
- 前端 domain/ 类型唯一来源，与后端 JSON 契约一一对应

## 目标用户

| 用户类型 | 需求特点                   |
| -------- | -------------------------- |
| 普通用户 | 只需粘贴链接，一键下载     |
| 进阶用户 | 需要选择清晰度、音轨、字幕 |
| 专业用户 | 需要解密、代理、自定义参数 |

## 项目范围

### 包含功能

- URL 输入与解析（类型徽章 + 引擎自动分派）
- 流信息预览与选择
- 多任务队列管理（并发控制 + 定时开始）
- 实时进度监控（速率曲线图表）
- 高级参数配置（任务级覆盖）
- 直播流录制
- 历史记录管理（DB 持久化 + overrides 快照）
- 任务预设系统（DB 持久化）

### 不包含功能

- 视频播放（调用系统播放器）
- 视频转码编辑
- 网络爬虫功能
- 云存储上传
- 广告过滤 UI（可用 `--urlprocessor-args` 命令行参数实现）
- 外部媒体导入（旧空壳，已移除）
- 命名模板（旧空壳，已移除）

## 成功标准

1. **功能性**：100% 覆盖 N_m3u8DL-RE 常用参数 + FFmpeg 直链下载
2. **易用性**：新用户 30 秒内完成首次下载
3. **稳定性**：连续运行 24 小时无崩溃
4. **性能**：内存占用 < 200MB，CPU 空闲时 < 1%
