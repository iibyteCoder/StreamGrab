# 界面设计方案

## 设计理念

### 核心原则

1. **渐进式披露** - 功能按需展开，避免信息过载
2. **视觉层次** - 重要信息优先，次要信息隐藏
3. **80/20 法则** - 80% 用户只用 20% 功能，优先展示核心
4. **一致性** - 统一的交互模式和视觉语言

### 设计风格

- **Modern Minimal** - 现代极简风格
- **Dark First** - 深色主题优先
- **Content First** - 内容优先，控件次要

│  │  📥 粘贴链接...                              [开始下载]   │ │

│  ───────────────────────────────────                            │
│  • 任务详细信息 (速度、时间、大小)                               │

### 用户场景分层

| 用户类型 | 使用频率 | 需要的层级 | 设计策略             |
| -------- | -------- | ---------- | -------------------- |
| 新手用户 | 偶尔     | Level 1    | 极简界面，一键下载   |
| 普通用户 | 经常     | Level 1-2  | 快速访问常用设置     |
| 高级用户 | 每天     | Level 1-3  | 完整功能，自定义配置 |

## 色彩系统

### 深色主题 (默认)

```css
:root {
  /* 背景层次 - 减少对比度 */
  --bg-base: #0a0a0a;
  --bg-surface: #111111;
  --bg-elevated: #1a1a1a;

  /* 边框 - 几乎不可见 */
  --border-subtle: #1f1f1f;
  --border-default: #2a2a2a;

  /* 文字 */
  --text-primary: #fafafa;
  --text-secondary: #888888;
  --text-muted: #555555;

  /* 强调色 - 克制使用 */
  --accent-primary: #3b82f6;
  --accent-success: #22c55e;
  --accent-warning: #f59e0b;
  --accent-error: #ef4444;
}
```

### 色彩使用原则

1. **克制使用强调色** - 只在重要操作和状态使用
2. **灰度为主** - 大部分界面使用灰度色
3. **功能色明确** - 成功/警告/错误颜色保持一致

## 动画规范

### 原则

1. **功能性动画** - 只为反馈使用，不为装饰
2. **快速响应** - 100-200ms 完成过渡
3. **自然缓动** - 使用 ease-out 而非 linear

### 常用动画

```css
/* 淡入淡出 - 200ms */
.fade {
  transition: opacity 200ms ease-out;
}

/* 展开/折叠 - 200ms */
.expand {
  transition: max-height 200ms ease-out;
}

/* 悬停效果 - 100ms */
.hover {
  transition: background-color 100ms ease-out;
}
```

## 设计决策总结

| 决策                          | 原因                            |
| ----------------------------- | ------------------------------- |
| 默认只显示 URL 输入和任务列表 | 符合 80/20 法则，满足大多数用户 |
| 设置放在弹出面板              | 减少主界面复杂度                |
| 流选择器按需显示              | 不是每次都需要选择              |
| 任务卡片默认折叠              | 可同时查看更多任务              |
