## 🎉 首个正式版本

StreamGrab 是一个基于 Tauri 2.0 + Vue 3 的现代视频流下载器 GUI，封装了 [N_m3u8DL-RE](https://github.com/nilaoda/N_m3u8DL-RE) 下载引擎。

## ✨ 功能特性

- 支持 HLS/DASH/MSS 流媒体下载
- 基于 N_m3u8DL-RE 的高性能下载引擎
- 现代化深色主题界面
- 多任务并行下载
- 实时下载进度显示
- shadcn-vue 组件库集成
- 下载历史记录功能
- 模块化设置组件系统

## 🛠️ 技术栈

- 前端: Vue 3 + TypeScript + TailwindCSS
- 桌面框架: Tauri 2.0
- 后端: Rust
- 下载引擎: N_m3u8DL-RE

## 📦 安装包

| 平台 | 文件 |
|------|------|
| Windows | `StreamGrab_0.1.0_x64-setup.exe` |
| macOS | `StreamGrab_0.1.0_x64.dmg` |
| Linux | `StreamGrab_0.1.0_amd64.AppImage` |
