## 🚀 功能大更新

本版本带来了大量新功能和改进！

## ✨ 新增功能

### 国际化 (i18n)
- 🌐 支持简体中文、繁体中文、英文三种语言
- 实时语言切换

### 系统托盘
- 📌 支持最小化到系统托盘
- 后台运行不干扰工作

### 流选择器
- 🎬 自动解析视频流信息
- 支持选择不同清晰度的视频流

### 模板管理
- 💾 保存下载配置为模板
- 一键复用常用配置

### 剪贴板监听
- 📋 自动检测剪贴板中的 M3U8 链接
- 快速添加下载任务

### 更新检查
- 🔄 启动时自动检查新版本
- 一键跳转下载页面

### 日志查看器
- 📝 实时查看下载日志
- 方便排查问题

### 网络设置
- 🌍 支持代理配置
- 并发连接数设置

## 🐛 修复

- 修复 TypeScript 类型错误
- 优化 GitHub Actions 发布工作流

## 📦 安装包
