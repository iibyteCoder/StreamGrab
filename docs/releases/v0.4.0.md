# StreamGrab v0.4.0

## ✨ 新增

- 📊 进度图表组件，支持实时下载速率曲线显示
- 🔔 通知系统，下载完成/失败时发送系统通知
- 🎯 广告关键词管理组件
- 📱 任务详情子组件（TaskStatusHeader、TaskBasicInfo、TaskMediaInfo 等）
- 📋 模板管理子组件（TemplateCard、TemplateEditDialog、TemplateDeleteDialog）
- 🎬 流列表组件（StreamItem、StreamList）

## 🚀 优化

- 🗄️ 新增进度历史数据库表（progress_history）
- 🗄️ 新增媒体信息存储功能
- 📦 添加 chart.js 和 vue-chartjs 依赖

## 🐛 修复

- 修复并发下载时媒体信息混乱问题
- 修复文件存在检测问题
- 修复文件大小不显示问题
- 优化进度条显示逻辑

## 🔨 重构

- ♻️ 重构后端下载命令模块，增强任务状态管理
- ♻️ 优化数据库 schema 和操作
- ♻️ 改进进程管理器和输出解析器
- ♻️ 拆分大型前端组件为更小的可复用单元
- ♻️ 优化服务层 API 调用和状态管理逻辑

## 📦 安装包

| 平台 | 文件 |
|------|------|
| Windows | `StreamGrab_0.4.0_x64-setup.exe` |
| macOS | `StreamGrab_0.4.0_x64.dmg` |
| Linux | `StreamGrab_0.4.0_amd64.AppImage` |
