## ✨ 新增

- 🔗 FFmpeg 引擎支持，可下载普通 HTTP 视频直链（.mp4/.mkv/.avi 等）
- 📦 工具管理中心，自动检测/下载 N_m3u8DL-RE 和 FFmpeg
- 🔄 工具版本检查和更新提醒功能
- 💡 Tooltip 组件，增强交互提示

## 🚀 优化

- 📝 使用 log crate 替代 println!，规范化日志输出
- 📄 更新 README 文档，完善项目介绍
- 📜 协议从 MIT 更改为 GPL-3.0

## 🔨 重构

- ♻️ 后端架构重构为分层架构
  - `app/` - 应用层（Tauri 命令、应用服务）
  - `domain/` - 领域层（实体、仓储接口）
  - `infrastructure/` - 基础设施层（数据库、进程管理、工具管理）
  - `shared/` - 共享模块（类型定义、错误处理）
- ♻️ 优化命令构建器，支持多引擎参数生成
- ♻️ 改进下载服务，支持引擎自动选择
