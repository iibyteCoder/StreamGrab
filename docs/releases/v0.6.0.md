# StreamGrab v0.6.0

## 📝 版本概述

v0.5.2 后的全面重构版本：后端重写为四层架构 + 引擎策略模式，前端重排为三段式添加向导与双栏设置中心，并修复了 N_m3u8DL-RE 新版本下进度显示全空的关键问题。

## ✨ 新增

- 📋 添加任务三段式向导（粘贴 → 逐条配置 → 完成提交）
  - 多行粘贴 + TXT 文件导入，自动分类流媒体/直链并剔除无效链接
  - 逐条配置卡 + 最近保存目录记忆下拉（上限 5、去重、最新在前）
  - 高级设置手风琴：引擎驱动动态项、内联流选择、解析失败可重试
- 🖱️ 任务卡片右键菜单：复制链接 / 文件名 / 保存路径，以当前链接重新下载（预填添加对话框）、打开详情
- 📎 任务详情面板一键复制下载链接（图标态切换 + toast 反馈）
- 🔄 启动时检测中断任务并弹窗恢复下载
- ⚠️ 添加已存在 URL 时弹窗确认（URL 重复检测）

## 🚀 优化

- ⚙️ 设置中心重构为 4 分区双栏导航（常规·界面 / N_m3u8DL-RE / FFmpeg / 任务预设）+ 统一工具管理卡片
- 📄 添加任务弹窗渐进披露：一级仅 URL，二级「更多选项」折叠
- 🖱️ 播放下载文件改用系统默认程序打开
- 🧹 移除「下载历史」前端页（与首页「进行中/已完成」分类冗余）与 3 个空壳功能（广告过滤/外部媒体导入/命名模板）

## 🐛 修复

- 🔢 修复 N_m3u8DL-RE 20260628 在非 TTY 下进度块粘连导致进度/速度/图表全空（parse_chunk 流式解析 + 双流聚合）
- 🎯 修复下载完成后进度数据丢失——退出瞬间倾泻的进度帧不再被丢弃（实测 0→53 事件、0→100%）
- 💥 修复预设编辑/删除弹窗 SelectItem 空值崩溃
- ⏰ 修复 keydown 监听告警与定时任务提前启动
- 💾 修复「恢复默认」设置不写回数据库的问题
- 🎨 修复浅色主题破图（tailwind alpha token 与 `--accent-*` 变量缺失）
- 🔧 修复升级后 FFmpeg 相对路径找不到（绝对化 + 存在性校验）

## 🔨 重构

- 🏗️ 后端四层架构 + 引擎策略模式：N_m3u8DL-RE / FFmpeg 按 URL 类型自动分派，命令行参数由引擎构建（前端零 CLI 知识）
- 🗄️ schema v4 单表聚合 + 三层配置模型（全局默认 + 任务级覆盖 + 引擎参数）
- 🛡️ 数据库版本不符时先备份 `.bak.<时间戳>` 再重建，用户数据不再直接丢失
- 🧪 测试体系建立：Rust 117 单元测试 + 前端 93 测试 + 实跑集成测试基建

## ⚠️ 升级提醒

本版数据库全新重建（schema v2 → v4），旧版设置、任务、预设**不会自动迁移**。首次启动时旧库会自动备份为 `streamgrab.db.bak.<时间戳>` 后重建空库，请重新配置。
