# StreamGrab v0.6.1

## 🐛 修复

- 🔍 下载失败时展示工具的详细错误，替代笼统的「进程退出码」
  - 自动从工具输出提取错误摘要（如 CDN 返回 `403 (Forbidden)`、`Download init file failed`），直接在任务失败提示与系统通知中展示
  - 便于用户自诊断：请求头缺失 / 链接失效 / 权限拒绝等一望即知

## 📦 安装包

| 平台     | 文件                            |
| -------- | ------------------------------- |
| Windows  | `StreamGrab_0.6.1_x64-setup.exe` |
| macOS    | `StreamGrab_0.6.1_x64.dmg`        |
| Linux    | `StreamGrab_0.6.1_amd64.AppImage` |
