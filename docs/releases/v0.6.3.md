## 📝 版本概述

本版建立了基于 chrome-devtools-mcp 的 E2E 测试体系（真实 Chrome 内跑通 49 个完整用户流程），并修复了测试期间发现的 3 个真实缺陷——其中「设置开关点击不生效」直接影响所有设置项、定时开始与仅下载字幕。同时流选择默认改为最高画质，应用图标换为圆角方块样式。

## ✨ 新增

- 🧪 E2E 测试体系：chrome-devtools-mcp 驱动真实 Chrome 跑 49 个端到端用例
  - 覆盖启动/托盘/中断恢复、添加任务向导、任务管理、下载生命周期、设置/i18n/主题、预设、剪贴板监控
  - `e2e/support/tauri-mock.js` 假后端 + Vite 注入，无需打包即可全流程回归
  - `npm run test:e2e` 一键运行，CI 已接入
- 🎬 流选择默认勾选最高画质视频流（带宽优先，其次分辨率，不再依赖列表顺序）
- 🎨 应用图标更新为圆角方块样式，全套平台图标（ico/icns/Android/iOS）重新生成

## 🚀 优化

- 🖱️ 托盘图标增加 tooltip「StreamGrab」：Windows 通知区域隐藏图标折叠区也能辨识并恢复
- 💬 最小化到托盘提示语补充「点击 ^ 展开隐藏图标、拖出 StreamGrab 图标」的操作指引（中/英/繁）

## 🐛 修复

- 🔘 修复设置开关（reka Switch）事件绑定错误导致点击不生效的问题——7 处 `@update:checked` → `@update:model-value`（影响设置页所有开关、定时开始、仅下载字幕等）
- 🌐 修复托盘创建失败提示 `{error}` 占位符被 vue-i18n 剥离的问题，改用命名参数传参
